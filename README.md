# タクシー業務前チェックアプリ (Taxi Work Check App)

このプロジェクトは、タクシー運転手の業務前点呼をデジタル化するためのPWA（Progressive Web App）です。

## 🚀 クイックスタート (Antigravityをお持ちの場合)

同じAIアシスタント（Antigravity）をお使いの場合、フォルダを開いて以下のように指示するだけで準備が整います：

> 「このアプリを起動して」

AIが自動的にライブラリのインストール（npm install）とサーバーの起動（npm run dev）を代行します。

---

## 🛠 手動での起動手順

Node.jsがインストールされている環境で以下のコマンドを実行してください：

1. **ライブラリのインストール**:
   ```bash
   npm install
   ```

2. **アプリの起動**:
   ```bash
   npm run dev -- --host
   ```
   ※ `--host` オプションにより、同じWi-Fi内のスマホ等からアクセス可能になります。

3. **アクセス方法**:
   表示されたURL（例: `https://192.168.x.x:5173`）にブラウザでアクセスしてください。
   カメラ機能を使用するため、**HTTPS** での接続が必須です。

---

## 📂 引継ぎ時の注意点
フォルダを圧縮して共有する際は、**`node_modules` フォルダを除外**して圧縮してください（容量が大きく、共有先での再インストールが推奨されるためです）。

## 📝 主な機能
- **運転手**: 健康アンケート回答、アルコールチェック動画撮影、管理者への通知。
- **管理者**: 運転手一覧の確認、動画・回答の閲覧、点呼の承認。
- **PWA対応**: iPhone/Androidのホーム画面に追加してアプリとして利用可能。
